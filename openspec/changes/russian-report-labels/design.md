## Context

Сводный отчёт (`summary.md`/`summary.csv`) генерируется в `Metrics/SummaryReport.cs` из метрик (`MetricsStore.LoadAll()`) и тайминга BenchmarkDotNet. Сейчас имена стратегий и заголовки столбцов — латинские коды; требуется локализовать их для аналитиков.

## Goals / Non-Goals

**Goals:**
- Русские названия стратегий (с кодом в скобках) в `summary.md` и `summary.csv`.
- Русские заголовки столбцов.
- Не менять числовые метрики, их сбор и внутренние кодовые имена (`Strategy.Name`).

**Non-Goals:**
- Локализация консольного вывода BenchmarkDotNet (`--list`, стандартные отчёты `*-report.csv`).
- Глобальная русификация всего проекта — только сводный отчёт.
- Переименование классов стратегий / метрик во внутреннем коде.

## Decisions

### D1: Словарь-маппинг названий стратегий
В `SummaryReport` добавляется словарь «код стратегии → русское название»:
`A_BatchInsert → Пакетный INSERT (A)`, `B_RawBinaryCopy → Двоичный COPY (B)`, `C_Linq2DbBulk → LINQ2DB BulkCopy (C)`, `D_EfChunk → EF Core батч (D)`, `E_NativeCopy → Нативный COPY (E)`.
*Обоснование:* централизованный маппинг, обращается при формировании строки `Стратегия`.
*Альтернатива:* логика по расшифровке в классе стратегии — отклонено: представление должно жить в отчёте, а не в стратегии.

### D2: Русские заголовки столбцов
Заголовки столбцов в обеих формах (`md`/`csv`) заменяются на русские: `Стратегия`, `Строк`, `Время, мс`, `Память клиента, МБ`, `CPU клиента (ядро), %`, `CPU клиента (все ядра), %`, `Активность сервера (оценка)`, `Полезные данные, байт`, `Накладные, байт`, `Отношение payload/overhead`, `Примечание`.
*Обоснование:* единый набор заголовков для обеих форм, читаемость для аналитиков.

### D3: Локаль числовых значений
Формат чисел (разделители) остаётся invariant (`CultureInfo.InvariantCulture`), меняются только текстовые подписи. В `.md`-таблице это не создаёт проблем; в `.csv` — заголовки на русском, как задумано.
*Обоснование:* не ломать числовые значения; локализуем только подписи.

## Risks / Trade-offs

- **[Изменение заголовков CSV может поломать скрипты разбора]** → Задокументированная инверсия: машинная разборка должна ориентироваться на русские заголовки; метерики/значения не меняются.
- **[Код стратегии важен для автоматики]** → Код сохраняется в названии в скобках `(A)`–`(E)`, поэтому привязка остаётся.
- **[Русские подписи в CSV-кодировке]** → CSV пишется в UTF-8; утилиты, читающие CSV, должны учитывать кириллицу (стандартная кодировка).

## Migration Plan

- Обновить `Metrics/SummaryReport.cs`: добавить маппинг стратегий и русские заголовки.
- Собрать и прогонять validation для проверки читаемости `summary.md`/`summary.csv`.
- Откат не требуется (чистое представление; при необходимости вернуть латинские подписи).

- Следует ли локализовать и README-таблицы метрик? — На усмотрение; в скоупе только отчёт-сводка.
