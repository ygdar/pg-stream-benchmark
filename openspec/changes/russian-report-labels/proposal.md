## Why

Сводный отчёт (`summary.md` / `summary.csv`) содержит названия стратегий в виде кодов (`A_BatchInsert`, `B_RawBinaryCopy`, …) и англоязычные заголовки столбцов (`TimeMs`, `PeakMemMB`, …). Для аналитиков, работающих с отчётом без знания кодовой логики проекта, такой вид нечитаем: непонятно, какая стратегия за каким кодом стоит, и что означает каждый столбец.

## What Changes

- В сводном отчёте (`summary.md` и `summary.csv`) названия стратегий заменяются на человекочитаемые названия **на русском языке**, с сохранением кода в скобках для однозначной привязки к стратегии:
  - `A_BatchInsert` → «Пакетный INSERT» (A);
  - `B_RawBinaryCopy` → «Двоичный COPY» (B);
  - `C_Linq2DbBulk` → «LINQ2DB BulkCopy» (C);
  - `D_EfChunk` → «EF Core батч» (D);
  - `E_NativeCopy` → «Нативный COPY» (E).
- Заголовки столбцов в отчёте-сводке переводятся на русский (например: `Стратегия`, `Время, мс`, `Память клиента, МБ`, `CPU клиента, %`, `Активность сервера (оценка)`, `Полезные данные, байт`, `Накладные, байт`, `Отношение payload/overhead`, `Примечание`).
- Изменение затрагивает только представление отчёта: метрики/числа и их вычисление остаются прежними, кодовые имена стратегий во внутренних артефактах (JSON-метрики, классы) не меняются.
- Задействован файл `Metrics/SummaryReport.cs` (генерация `.md` и `.csv`).

## Impact

- **Код**: только представление отчёта в `Metrics/SummaryReport.cs` (маппинг названий стратегий и заголовков на русский). Числовые метрики и их сбор не меняются.
- **Формат данных**: как `.md`, так и `.csv` сводки используют русские подписи; коды стратегий сохраняются в скобках для привязки.
- **Обратная совместимость значений**: строки/CSV-машинная разборка может зависеть от заголовков — заголовки становятся русскими (задокументированный вывод).
- **Внутренние данные**: JSON-метрики и код стратегий (`Strategy.Name`) остаются латиницей без изменений.
