## ADDED Requirements

### Requirement: Единый отчёт-сводка
После прогона бенчмарков система SHALL формировать один общий файл-сводку по всем запущенным бенчмаркам текущего прогона, объединяющий время и ресурсные метрики всех стратегий × размеров. Сводка генерируется в дополнение к отдельным отчётам по каждому бенчмарку.

#### Scenario: Сводка по всем запущенным бенчмаркам
- **WHEN** завершается прогон с несколькими запущенными бенчмарками
- **THEN** в одном общем файле содержится сводка по всем этим стратегиям × размерам

#### Scenario: Состав сводки
- **WHEN** формируется отчёт-сводка
- **THEN** для каждой стратегии по каждому размеру присутствуют время, память клиента, CPU клиента/сервера и payload/overhead ratio

#### Scenario: Актуальность по текущему прогону
- **WHEN** начинается новый прогон
- **THEN** файл-сводка генерируется по бенчмаркам именно этого прогона (а не по историческим данным)
