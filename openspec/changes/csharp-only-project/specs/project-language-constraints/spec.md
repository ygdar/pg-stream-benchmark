## ADDED Requirements

### Requirement: Только C# (.NET)
Весь проект (код, зависимости, скрипты сборки/экспериментов, документация) SHALL быть реализован исключительно на C# (.NET). Никакой код вне C# и никакие зависимости вне .NET-стека не допускаются.

#### Scenario: Проверка исходников
- **WHEN** выполняется обзор репозитория
- **THEN** все исходные файлы проекта представляют собой C# (.NET) и не содержат других языков разработки

#### Scenario: Добавление новой зависимости
- **WHEN** в проект добавляется новая библиотека/инструмент
- **THEN** она является .NET (NuGet)-зависимостью и интегрируется из C#-кода

### Requirement: Категорический запрет Java
Java и JVM-стек SHALL NOT использоваться в проекте ни в каком виде: Java-код, Kotlin, Groovy, JVM/Scala, Maven/Gradle-скрипты, Java-библиотеки или документация на Java-стеках. Требование применяется ко всему проекту вне зависимости от отдельного домена или цели.

#### Scenario: Проверка отсутствия Java-артефактов
- **WHEN** выполняется проверка репозитория на соответствие стеку
- **THEN** не обнаруживается Java-исходников, JVM-конфигураций, Maven/Gradle-файлов или Java-зависимостей

#### Scenario: Предложение Java-решения
- **WHEN** предлагается изменение, использующее Java/JVM-компонент
- **THEN** изменение отклоняется, и предлагается эквивалент на C# (.NET)

### Requirement: linq2db — исключительно C#-библиотека
linq2db SHALL рассматриваться как только и исключительно C#-библиотека доступа к данным. Официальный источник — https://github.com/linq2db/linq2db. linq2db SHALL NOT ассоциироваться с Java/JVM и SHALL использоваться только из C#-кода через NuGet-пакет.

#### Scenario: Документирование первоисточника
- **WHEN** в документации или код-ревью упоминается linq2db
- **THEN** оно ссылается на C#-репозиторий https://github.com/linq2db/linq2db и не упоминает Java

#### Scenario: Использование из C#
- **WHEN** linq2db используется в проекте
- **THEN** оно подключается как .NET (NuGet) пакет и вызывается из C#-кода

#### Scenario: Недопустимая Java-ассоциация
- **WHEN** linq2db ошибочно предлагается использовать как Java-библиотеку
- **THEN** такое использование отклоняется с указанием, что linq2db — это C#-библиотека
