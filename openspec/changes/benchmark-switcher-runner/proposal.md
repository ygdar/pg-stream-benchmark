## Why

Сейчас входная точка (`Program.cs`) жёстко запускает все 5 стратегий последовательным циклом `foreach BenchmarkRunner.Run` по захардкоженному массиву типов. Невозможно быстро отобрать нужные стратегии из командной строки — приходится править код. BenchmarkDotNet уже предоставляет декларативный движок и нативный отбор через `BenchmarkSwitcher` (`--filter`, `--list`), который не используется.

## What Changes

- `Program.cs` переписывается с цикла `foreach BenchmarkRunner.Run` на `new BenchmarkSwitcher(...).Run(args, config)`.
- Появляется отбор бенчмарков из консоли:
  - `--filter "*<Стратегия>*"` — запустить только выбранные стратегии (главный сценарий);
  - `--list flat` / `--list tree` — показать список бенчмарков без запуска;
  - без аргументов — запустить все 5 стратегий (поведение как раньше).
- Сохраняются без изменений: `--mode` (validation/dev/full), абсолютный путь данных через env-переменную `DBBENCH_DATA_DIR`, выбор `Job` по режиму (ShortRun vs лёгкие итерации), `ManualConfig` с Job.
- README.md — в раздел «Запуск» добавляются примеры использования `--filter` и `--list`.
- Никаких изменений в benchmark-классах (декларативный подход `[Benchmark]`/`[GlobalSetup]`/`[ParamsSource]` уже реализован и остаётся как есть).

## Capabilities

### New Capabilities
- `benchmark-selection`: Отбор запускаемых стратегий бенчмарка из командной строки через BenchmarkSwitcher (`--filter`), а также перечисление бенчмарков (`--list`) без изменения существующего декларативного описания.

## Impact

- **Код**: только `benchmark/Program.cs` (замена цикла на switcher) + документация в `README.md` (раздел «Запуск»).
- **Benchmark-классы**: без изменений — они уже декларативные (`[Benchmark]`, `[GlobalSetup]`, `[ParamsSource]`).
- **Зависимости**: нет новых — `BenchmarkSwitcher` из уже подключённого `benchmarkdotnet`.
- **Поведение по умолчанию**: запуск без аргументов (`--filter`) остаётся «запустить все стратегии», режимы/размеры по-прежнему управляются `--mode`.
- **Ограничение**: фильтр выбирает стратегию (класс бенчмарка), а не размер — размеры остаются привязаны к `--mode`.
